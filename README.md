## 🚀 Aceder ao site

👉 [Clica aqui para visitar o portfólio](https://tallitaoliveira.github.io/portfolio-tallita/)

## 📋 Sobre o projeto

Site de portfólio pessoal com 4 secções interligadas por um menu de navegação fixo, desenvolvido com HTML5, CSS3 e JavaScript.

## 📄 Páginas / Secções

- **Sobre mim** — apresentação pessoal e hobbies
- **Formação** — formação acadêmica, cursos e idiomas
- **Portfólio** — projetos desenvolvidos
- **Contato** — formulário com validação em Js e links para redes sociais

## ✨ Funcionalidades

- Navegação por âncoras (Single Page)
- Menu responsivo com botão hamburguer para mobile
- Alternância entre tema claro e escuro
- Formulário de contato com validação em JavaScript
- Layout responsivo com Flexbox, CSS Grid e Media Queries

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (sem frameworks)
